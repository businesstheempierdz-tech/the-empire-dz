# نشر متجر The Empire DZ على Vercel

هذا المشروع جاهز للنشر على Vercel.

## الطريقة الأسهل

1. ادخل إلى https://vercel.com
2. سجل بحسابك عبر Google أو GitHub.
3. اضغط Add New ثم Project.
4. ارفع أو اربط مشروع The Empire DZ.
5. عند الإعدادات اترك Vercel يكتشف المشروع تلقائياً كـ Vite.
6. اضغط Deploy.

## بعد النشر

سيعطيك Vercel رابطاً مثل:

https://the-empire-dz.vercel.app

ضع هذا الرابط في:

- Bio إنستغرام
- صفحة فيسبوك
- وصف واتساب Business
- المنشورات والإعلانات

## إعدادات مهمة

- Build command: npm run build
- Output directory: dist
- Framework preset: Vite

## ملاحظة

ملف vercel.json مضاف حتى يعمل الموقع بشكل صحيح عند فتح أي رابط داخلي مستقبلاً.
